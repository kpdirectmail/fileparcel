# Third-party software in FileParcel

FileParcel is licensed under the Apache License, Version 2.0 (see `LICENSE`). The FileParcel binary is a
statically linked Go program that includes the Go standard library and the Go modules listed below; the
web app includes icons derived from Lucide, and the binary embeds a password word list derived from
zxcvbn. Each component remains under its own license. This file reproduces their copyright notices and
license texts as required for binary distribution; notices required by Apache-2.0 components are also
collected in `NOTICE`.

The module list is exactly the set of modules linked into the binary (`go version -m bin/fileparcel`);
`scripts/check-third-party.sh` verifies that this file is complete after dependency changes.

### Container image

The Docker image (`Dockerfile`) is built with the official `golang:1.27.1` image (build stage only) and runs on
`gcr.io/distroless/static-debian12:nonroot` (the distroless project is Apache-2.0), which contains a few Debian
packages such as `base-files`, `netbase`, `tzdata` and `ca-certificates` under their own licenses; their copyright
files are in `/usr/share/doc/*/copyright` inside the image.

### zxcvbn password frequency list

8+ characters) of the password frequency list shipped with zxcvbn, which derives it from Xato's public
10-million-password corpus. Only the word list is used; no zxcvbn code is linked into the binary.
